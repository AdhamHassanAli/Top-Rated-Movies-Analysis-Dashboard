# Top-Rated-Movies-Analysis-Dashboard
A Power BI dashboard analyzing 250 highly-rated movies (8.0+ rating) across decades. Features release trends by decade/year, score distributions, and interactive visualizations. 

# Key Features:

100+ years of movie data (1920s-2020s)

Decade-wise release patterns

Average score analysis (8.31/10)

Interactive filters and detailed movie listings
